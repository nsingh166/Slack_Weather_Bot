# Slack Weather Assistant

A Python-based Slack application that automates weather reporting and provides AI-assisted interactions within Slack. The project combines weather data retrieval, scheduled message delivery, and conversational AI integration to create a simple but useful workplace assistant.

## Overview

This project automatically retrieves weather information and posts updates to a designated Slack channel on a scheduled basis. In addition, users can interact with the application through Slack and receive AI-generated responses to questions and prompts.

The goal of the project is to gain hands-on experience with API integration, workflow automation, Slack application development, and AI-powered features.

## Features

* Automated weather updates delivered to Slack
* Scheduled execution using GitHub Actions
* Weather data retrieval through external APIs
* AI-generated responses through Slack interactions
* Cloud-based automation and deployment
* Continuous operation without manual execution

## Technologies Used

* Python
* Slack API
* OpenAI API
* GitHub Actions
* Git
* GitHub

## How It Works

1. Weather data is retrieved from external weather services.
2. Weather reports are formatted and delivered to Slack channels.
3. GitHub Actions handles automated scheduling and execution.
4. Users can send messages through Slack and receive AI-generated responses.
5. The application processes requests and returns relevant information directly within Slack.
